# Weed Control

Minecraft Java 版資源包，可隱藏草叢、蕨類、花朵等植物，讓地面更容易看清楚。植物仍保留在世界中，各版本隱藏的種類略有不同。

## 下載

依遊戲版本選擇一個 ZIP 檔。

| 適用版本 | 下載資源包 |
| --- | --- |
| Java 1.6–1.7 | [Weed control - 1.6-1.7.zip](https://raw.githubusercontent.com/ap2332/Weed-control/main/Weed%20control%20-%201.6-1.7.zip) |
| Java 1.8–1.12 | [Weed control - 1.8-1.12.zip](https://raw.githubusercontent.com/ap2332/Weed-control/main/Weed%20control%20-%201.8-1.12.zip) |
| 較新版 Java（資源包宣告支援格式 4–104） | [Weed control.zip](https://raw.githubusercontent.com/ap2332/Weed-control/main/Weed%20control.zip) |

## 安裝

1. 在 Minecraft 主選單開啟「選項」→「資源包」→「開啟資源包資料夾」。
2. 將下載的 ZIP 原檔放進資料夾，無須解壓縮。
3. 回到資源包畫面，啟用 Weed Control。如果同時使用其他植物材質包，將 Weed Control 移到它們上方。
4. 按「完成」並進入世界，到原本有草叢或花朵的位置查看效果。

1.8–1.12 版的 ZIP 使用 `pack_format: 1`，部分遊戲版本可能顯示相容性提示。
